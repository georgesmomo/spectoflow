# Write tests

## Steps
1. For each acceptance criterion, write a failing test (red).
2. Pick the level (unit / integration / e2e) for the scope.
3. No real secrets; isolated test data.

## Output
Executable red tests + the command to run them. Record results in `.spectoflow/runtime.json`.
