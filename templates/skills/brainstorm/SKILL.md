# Brainstorm

## Steps
1. Draw out the problem, the users, the scope and what is explicitly out of scope.
2. Offer 2-3 directions with trade-offs; let the user react.
3. Converge on a shared understanding. Do not write code or a full spec yet.

## Output
A short problem statement and agreed scope, ready for analysis.
