# Write spec

## Steps
1. State the purpose (1-2 sentences).
2. List requirements; for each, one or more scenarios (WHEN … THEN …).
3. Note out-of-scope and open questions.

## Output
`specs/<feature>.md`. Show it, get explicit sign-off, revise on feedback.
