# Write plan

## Steps
1. Group work into phases (## headings). Data before services, services before UI.
2. Each task = a checkbox line: `- [ ] T-xxx Title @owner ~level`.
3. Make dependencies and order explicit.

## Output
`plans/<feature>.md` with checkbox tasks the dashboard can track.
